HOW THE AI SEARCH WORKS

It explores states, one safe move at a time.

1

Start State

All disks begin in Storage A. A state means the current disk arrangement.

2

Queue Search

The program puts states in a queue and checks them in order. This is BFS.

3

Safe Moves Only

It moves only the top disk, and never puts a larger disk on a smaller one.

4

Visited States

Already-seen arrangements are remembered, so the search does not repeat them.
